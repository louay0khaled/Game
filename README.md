# Tap Rush 🎯

لعبة أندرويد بسيطة وسريعة: اضغط على الهدف الأزرق بأسرع ما يمكن خلال 30 ثانية واجمع أكبر عدد من النقاط.

## البناء

المشروع يستخدم Gradle وAndroid Gradle Plugin، وGitHub Actions يبني ملف APK تلقائياً عند كل push إلى `main`.

ملف الـAPK الناتج موجود ضمن Artifacts باسم `Tap-Rush-debug-apk`.
