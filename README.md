# ZERO // أنت شبحك الخاص

لعبة Android 2D سينمائية ومتكاملة، مبنية بالكامل بدون اتصال بالإنترنت.

## الفكرة

كل مرحلة تسجل مسارك. عندما تنتقل للمرحلة التالية يعود مسارك السابق كـ **Echo** متحرك أمامك، بينما تتغير العقد وتزداد الصعوبة. هدفك إكمال 12 مرحلة والوصول إلى الصفر قبل أن تهزمك ذاكرتك.

## المميزات

- واجهة فخمة بطابع sci‑fi داكن.
- العربية والإنجليزية مع زر تبديل داخل اللعبة.
- 12 مرحلة تصاعدية وصعوبة متزايدة.
- نظام Echo يعرض المسار السابق كشبح.
- نقاط، أفضل نتيجة، وسلسلة ضربات محفوظة محلياً.
- مؤثرات لمس واهتزاز وصوت خفيف.
- تأثيرات جزيئات عند الإصابة الصحيحة.
- يعمل Offline ولا يحتاج خادم أو حساب.
- أيقونة ZERO مخصصة.
- APK يُبنى تلقائياً عبر GitHub Actions عند كل push إلى `main`.

## البناء

استخدم GitHub Actions workflow باسم **Build APK**. الملف الناتج هو `app-debug.apk` داخل Artifact باسم `Tap-Rush-debug-apk` (سيتم اعتماد اسم جديد في الإصدارات القادمة).
